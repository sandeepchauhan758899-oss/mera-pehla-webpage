# Mera Pehla Webpage 🌍

Swagat hai! Ye meri pehli website hai jise maine HTML ka upyog karke banaya hai. Is project mein maine prakriti aur bhugol (geography) se jude vibhinn vishayon ko cover kiya hai.

## 📂 Website ke Pages:
* **Home Page (`index.html`):** Website ka mukhya darwaza.
* **Climate (`climate.html`):** Jalvayu ke baare mein jaankari.
* **Earth & Space (`earth-space.html`):** Dharti aur antariksh ke tathya.
* **Volcano (`volcano.html`):** Jwalamukhi ke baare mein dilchasp baatein.
